# SanjivniAI

SanjivniAI is a polished AI-powered healthcare experience built with React, Vite, Tailwind CSS, and Firebase. It includes authentication, Firestore-backed health tracking, Gemini-powered symptom and image insights, doctor discovery, appointment planning, emergency support, and a modern dashboard experience.

## Features
- Secure sign in and sign up flow
- Protected dashboard and care pages
- AI symptom and image analysis support
- Doctor and pharmacy discovery experience
- Appointment and medical history tracking
- Emergency SOS, health tips, risk score, and AI care assistant
- SEO, error boundary, offline banner, and not-found experience

## Getting started
1. Install dependencies: npm install
2. Create a .env file with:
   - VITE_FIREBASE_API_KEY
   - VITE_FIREBASE_AUTH_DOMAIN
   - VITE_FIREBASE_PROJECT_ID
   - VITE_FIREBASE_STORAGE_BUCKET
   - VITE_FIREBASE_MESSAGING_SENDER_ID
   - VITE_FIREBASE_APP_ID
   - VITE_GEMINI_API_KEY
3. Run locally: npm run dev
4. Build for production: npm run build

## Deployment
This project is ready for Vercel. Add the Vercel config file and deploy the root folder.
